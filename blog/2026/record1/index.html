保研之路（申请篇）

Created on May 09, 2026

2026   ·   保研   ·   经验分享

此帖用来自我记录一下保研的进程，也希望能够帮助到后来的学弟学妹。 本篇章主要谈谈我在夏令营以及预推免申请上遇到的一些问题以及经验。

首先是夏令营阶段

学校 入营情况 结果 备注
中科大科学岛 x x 从去年起就开始卡9了，不意外
吉大计院 入营 没去 bar对于2本来说bar应该不高，不报销路费所以懒得去了
山大软院 入营 无效力 线上大海营，群里人数1000＋
北航宇航/软件学院 入营 无效力 两个都是线上宣讲营，应该报了就入，软件学院还有个神秘机考，想做就做吧，也没人抓作弊
深大计院 入营 没去 候补的第二批给了入营，后续好像候补到了第四批，很多人都是报了不去，应该想入都能等到
南航计院 x x 大概是OQ了
南科大生医工 x x 夏令营的时候计院没开，故报了个BME，结果没入
武大应数中心 入营 无效力 宣讲营
川大计院 x x 川大大概是每个学院只放报名的rk最高的人入了（只按学院为单位，跨专业对比），无效力
西交网安 入营 优营 西交网安比较特殊，要自己联系老师，然后跟着老师做项目，老师会推荐优秀营员上学院，通知上说是无效力，但是据老师透露会有优势
华师计院 x x 弱com，没联系老师
西工大网安 入营 无效力 宣讲营
天大网安/人智/计院 x x 全军覆没，今年莫名的bar高，不过夏令营无效力，可能也是因此所以不筛OQ了
软件所 入营 没去 提前联系了老师，推荐入营了，但是线下参营前给我鸽了，直接没去线下了，没有联系老师大概率拿不到offer
信工所 x x 信工所没入营也是挺意外的，比我bg差的很多都入营了，很迷
工人所 x x 第二年招生，bar依旧很高
电科网安优本计划 x x 强com
国防科大计院（第一批） x x 没入营也是很意外，报的还是冷门的网安，今年的bar水涨船高
北理珠AI x x 本校有两位bg比我差的进了，可能是因为我报的是AI，他们报的是计算机技术，所以说保研还是挺看运气的（，不过也是无效力
武大网安 入营 无效力 宣讲营
北理叉院 x x 虽然没入营，但是有老师单独给我打电话让我参加面试，做的方向太偏，拒了
中南AI x x 貌似是第一年招生，无太多信息
厦大信院通信系 入营 x 最恨的一集，据我身边消息可知，2位211的3%以及1位5%被斩了，2的9%、本校中低rk以及本地双非的优了😅😅😅

然后是预推免阶段

学校 入营情况 结果 备注
南科大计院 已报名 x 等待
北邮网安 x x 等待
央民信工 入营 没去 入营好像还要交100块钱，bar比较低
东南网安 入营 等待 两分钟中文自我介绍➕英语提问➕综合面试，体验感很好，老师基本不压力，按排名分配学硕，专硕，无锡专硕，英语提问有挺多可能性的，有些让你翻译上一个人的简历，有些让你介绍自己的项目，比较综合性的考核，综合面试就是拷打你的项目为主，有些会问专业课
深先院数字所 等待 等待 等待
南开卓工 等待 等待 工程硕博项目，报名了专硕
武大应数 等待 等待 很贵的一个专硕项目，个人感觉家庭经济条件允许的情况下，性价比很高
